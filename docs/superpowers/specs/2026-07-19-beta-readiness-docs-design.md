# Beta Readiness Docs Design

## Goal

Make LiveAstro Studio tryable and reviewable while real observing is blocked by weather or logistics.

## Scope

This is documentation only. It does not change app behavior or the release artifact currently submitted to Apple notarization.

## Deliverables

- `docs/beta-quickstart.md`: a short no-sky path using `fakesiril`.
- `docs/beta-checklist.md`: a structured checklist for local, OBS, packaging, import, and future field validation.
- README links that make the no-sky demo discoverable from the public front door.
- User guide pointer so beta testers can find the quickstart/checklist.

## Tone

Public beta language: practical, friendly, and honest about what the no-sky demo proves versus what still requires a real night.
