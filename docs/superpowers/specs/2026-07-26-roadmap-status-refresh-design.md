# Roadmap Status Refresh Design

## Goal

Keep `docs/roadmap.md` useful as a live product map by marking shipped polish items and clarifying what remains.

## Scope

Update roadmap wording only:

- mark the start workflow chooser as shipped;
- mark **Stack Previous Shoot…** wording as shipped;
- mark output discoverability as shipped;
- split demo work into shipped command-line `demo-stack` and future in-app demo mode;
- mark shipped operational-polish slices: `latest.png`, session health summary, output footprint display/support bundle;
- leave future items such as problem notifications, local status page, visual identity, and previous-shoot quality workflow intact.

## Non-goals

- No Swift source changes.
- No roadmap item deletion merely because it is hard.
- No new commitments to dates.
